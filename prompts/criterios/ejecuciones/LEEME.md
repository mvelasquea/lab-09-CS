# Ejecuciones para el análisis de no determinismo (E7.3) — PENDIENTE DEL EQUIPO

Estas carpetas deben llenarlas ustedes con respuestas **reales y sin editar**:

1. Abran **3 chats nuevos** en su asistente (Claude.ai, ChatGPT, etc.).
2. En cada chat peguen el prompt `v3` ya renderizado para **H1, H2 y H5** (reemplacen `{{id}}` y `{{historia}}`
   con los datos de `casos.yaml`).
3. Guarden cada respuesta tal cual en `run1/H1.txt`, `run2/H1.txt`, `run3/H1.txt`, etc.
4. Ejecuten `python scripts/comparar_ejecuciones.py prompts/criterios/ejecuciones`.
5. Redacten las 5 líneas de análisis en `prompts/seguridad/no-determinismo.md`.

No se incluyen respuestas de ejemplo: inventar variaciones invalidaría el ejercicio.
